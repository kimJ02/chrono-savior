# 챕터·스테이지 구조 (2026-11-19 사용자 확정)

예전 구조(원본 시제품): 지역 9개 일렬, 지역마다 몬스터 100마리(여러 판 누적) → 필드 끝 보스 포탈 → 보스 → 다음 지역. 회귀하면 지역 진행이 전부 지워진다.

## 새 구조

| 항목 | 확정 내용 |
|---|---|
| 구조 | 챕터 5개 × (일반 스테이지 5 + 보스 스테이지 1) = 일반 25 + 보스 5 |
| 이름 | 스테이지는 번호만(1-1 ~ 1-5, 보스). 챕터 이름은 임의(챕터 1 = Figma "스산한 들판") |
| 여는 순서 | 챕터 안에서 1 → 2 → 3 → 4 → 5 → 보스. 보스 스테이지는 1~5를 모두 깨야 열린다. 보스를 잡으면 다음 챕터 1스테이지가 열린다 |
| 일반 스테이지 클리어 | 그 스테이지에서 몬스터 100마리. 나갔다 들어와도 누적, 스테이지끼리 따로 센다. 다 채우면 "스테이지 클리어" 알림만 띄우고 시간이 끝날 때까지 계속 사냥 |
| 5스테이지 | 100마리를 채우면 필드 끝 포탈이 열린다 → 들어가면 중간 보스. 중간 보스를 잡아야 5스테이지 클리어 |
| 중간 보스 | 그 스테이지 몬스터를 키운 것 — 크기 2배, 체력 20배, 공격력 5배 |
| 보스 스테이지 | 스테이지 선택에서 바로 보스전. 챕터 1 = 덩어리 지배자(예전 1지역 보스), 챕터 2 = 부서진 여신(예전 2지역 보스) |
| 챕터 3~5 | 아직 보스가 없어 **챕터 전체를 잠근다**(들어갈 수 없음). 지금 플레이 가능한 건 챕터 1~2 |
| 몬스터 | 지금 있는 몬스터(전부 예전 1스테이지 몬스터)를 모든 챕터에 쓴다 |
| 스테이지 난이도 | 챕터 = 예전 지역 번호(난이도·회귀 장벽·보스·하늘색). 챕터 안 스테이지별 상승은 GPT와 정함(아래) |
| 환생(시간 회귀) | **챕터·스테이지 진행과 처치 수는 지우지 않는다.** 예: 챕터 2까지 깨서 다음이 3-1이면 환생 후에도 3-1부터, 이미 깬 스테이지는 전부 열린 채. 레벨·골드·골드 강화·스킬은 지금처럼 초기화, 유물·파편은 유지. 이유: 날짜 제한(7일) 안에 플레이어가 자기 실력에 맞는 곳을 골라 다시 성장·파밍하게 |
| 시간의 파편 | 원본 계산을 유지. 단, 진행이 안 지워지므로 같은 진행으로 매번 다시 받지 않게 조정(GPT와 정함) |
| 회귀 장벽 | 원본 그대로 적용(챕터 번호 기준) |
| 멸망 날짜 | 스테이지(보스 포함)에 들어갈 때마다 하루, 7일 그대로 |
| 세이브 슬롯 | 2번 = 챕터 1 전체 클리어(다음 2-1), 3번 = 챕터 2까지 클리어(다음 3-1 — 잠겨 있으니 챕터 1~2를 다시 돈다) |
| 화면 | Figma 그림은 **캡처가 아니라 원본 이미지로 받는다**(사용자). Figma "마왕성 길목 선택"(32:56) 두 화면. 섬 지도 한 장(모든 챕터 공용). **지도 위 리본 5곳 = 그 챕터의 스테이지 1~5**(사용자 2026-11-19 정정): 1 오른쪽 아래 숲 · 2 가운데 아래 마을 · 3 왼쪽 위 산 · 4 오른쪽 설산 · 5 오른쪽 위 하늘 신전. 스테이지에 마우스를 올리거나 방향키로 고르면 그 자리 위에 ▼ 화살표(Figma "선택 1", 원본 그림 1:1). 아래 띠 ◀ 챕터 ▶ 로 챕터를 넘기고, 띠의 칸 5개도 스테이지. 오른쪽 판 = 스테이지 이름·등장 몬스터 3칸·진행도 막대·원정 떠나기. 보스 스테이지를 고르면 빨간 화면(보스 정보·이름·주요 패턴 2칸). **도트가 깨지지 않게 그림은 1:1(정수배)** |

## GPT와 정한 값(2026-11-19)

- **스테이지 난이도**: 난이도 지수 `T = (챕터-1) + (스테이지-1)/5`. 몹 체력 = 기본 × 2.15^T, 공격력 = 기본 × 1.4^T, 골드·경험치 = 1.42^T.
  레벨 = 추천 레벨(챕터) + [0,1,1,2,2][스테이지-1] + 0~1. → 1-5 → 2-1이 매끄럽게 이어진다(체력 ×1.17, 공격력 ×1.07).
- **중간 보스**: 5스테이지 몹 수치에 크기 ×2, 체력 ×20, 공격력 ×5(사용자 확정), 골드·경험치 ×10. 레벨은 5스테이지 몹과 같다.
  100마리 처치 수에 안 들어가고, 중간 보스 처치로만 5스테이지 클리어. 포탈 이동은 같은 판이라 날짜를 다시 쓰지 않는다.
- **챕터 보스**: 기존 보스 수치(지역 = 챕터)에 한 단계(체력 ×1.167, 공격력 ×1.070, 보상 ×1.072) 더. 레벨 = 추천 레벨 + 3.
- **시간의 파편**: 회귀할 때 **이번 생에 잡은 챕터 보스**마다 한 번씩 `max(1, floor(c² × 0.6))` = 1·2·5·9·15. 영구 클리어 기록과 별도로 "이번 생 처치" 기록을 두고 회귀 때 정산·초기화. 같은 보스를 한 생에 여러 번 잡아도 한 번. 회귀 조건은 원본대로(받을 파편 1개 이상, 단 멸망 0일이면 0개로도).
- **챕터 이름**: 1 스산한 들판 · 2 부서진 성역 · 3 멎은 시계숲 · 4 되감긴 심연 · 5 시간의 마왕성.
